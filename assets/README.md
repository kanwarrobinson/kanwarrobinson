## Image Guidelines

### Format
- Use **JPG** for photos (profile, projects, testimonials)
- Use **PNG** for logos and icons (company logos, favicon)
- Use **WebP** for better performance (optional)

### Size
- Keep images under 500KB for fast loading
- Use tools like [TinyPNG](https://tinypng.com/) to compress images
- Consider using responsive images for different screen sizes

### Resolution
- Profile: 400x400px (square)
- Projects: 800x600px (4:3 ratio)
- Company logos: 100x100px (square, transparent background)
- Testimonials: 200x200px (square)
- Favicon: 32x32px or 64x64px

## Tips

1. **Consistent Style**: Use images with consistent style and color scheme
2. **Optimize**: Always compress images before uploading
3. **Alt Text**: Images have alt attributes for accessibility
4. **Fallbacks**: The portfolio includes fallback images if yours fail to load
5. **Copyright**: Only use images you own or have permission to use

## Note
The portfolio will still work without images - it uses placeholder images as fallbacks!
